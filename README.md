# OUR ORBIT · 夜空相册原型

独立网页原型，未修改现有 Taro 小程序或云函数。无需安装依赖。

## 本地运行

在本目录运行 `node server.mjs`，打开 http://127.0.0.1:4173 。端口可通过 `ALBUM_PORT` 环境变量设置。服务器只监听本机；不适合直接作为线上服务。

## GitHub Pages 发布

将此目录的网页代码提交到单独的 GitHub 仓库 `main` 分支，并在仓库 **Settings → Pages → Build and deployment** 选择 **GitHub Actions**。仓库内的 `.github/workflows/pages.yml` 会自动发布静态网页；项目仓库地址对应的固定网址通常是 `https://<用户名>.github.io/<仓库名>/`。

**不要把私人照片、`photo-prep/output`、原图或视频提交到公开仓库。** 当前网页的 IndexedDB 仅保存在打开网页的那台设备与浏览器中。发布网页代码后，两个人可以打开同一个网址，但不能自动看见彼此导入的照片。真正共享照片还需接入带双人权限的私有云存储与数据库。

## 已实现

- 参照原作者开源仓库中的 Card Gallery 与 Image Atlas 交互，在“星轨”加入圆环、弧形、叠放、展开四种可平滑切换的卡片布局；“穿梭”展示完整照片库，复现参考视频开头的密集立体照片空间：拖动平移、滚轮或手机双指缩放，点击照片会飞近，再点可打开详情。“平铺”展示相册分类封面。未导入照片时用 240 张示例卡片演示穿梭布局，不会将示例存入照片库。网页封面与星空粒子背景未改动。
- 桌面可点击三种布局；星轨可横向拖动或用方向键浏览照片，纵向滚轮切换布局；穿梭中拖动平移、滚轮穿行，点“回到全景”复位。手机可滑动和点按控制。引入的布局思路来自 [Haichao Li 的开源仓库](https://github.com/HaichaoLihc/create-photo-flipbook-ui)，许可文字见 `UPSTREAM-LICENSE.txt`。
- 夜空星轨每天从照片库选出最多 100 张照片；按上海日期自动换组，同一批 1000 张照片会在连续 10 天轮到一遍。星轨横向滑动有短暂惯性；穿梭可随时查看全部照片，平铺视图展示相册分类。
- 星空首页不再附带下方照片列表。“所有回忆”通过独立路由 `#collection` 打开列表页面，保留搜索、收藏、相册管理和照片详情；“返回星空”回到 `#album`。支持刷新、浏览器前进/后退，手机顶部同样显示入口。
- 默认网址或 `#cover` 打开原有全屏动态封面，星空/列表顶部新增明确的“封面”返回按钮。`#album` 是相册内部的直接入口，不会删除或替换封面。
- “平铺”展示相册分类封面而非单张照片，每本相册显示首张照片与数量，空相册显示占位封面。点击通过 `#collection?album=...` 查看该相册照片，支持直接刷新和浏览器返回；分类来源于实际相册数据。
- 根据用户提供的封面提示词加入全屏视频入口：三段视频淡入淡出切换、Figtree 字体、超大 YT. 标题、上海时钟、手机折叠菜单。点击进入后才展示相册，返回/前进可在封面与相册间导航。
- 根据用户最新录屏改为黑底、细小星点向前漂移的实时星空。WebGL 逐粒子绘制，按设备像素比适配，最高 8,294,400 渲染像素（4K 3840×2160）；最多 18,000 个有远近层次的星点。GPU 不可用时降级到 Canvas 2D，背景与照片旋转可分别暂停，隐藏时停绘，遵从减少动态效果设置。
- 移除相册中央的标题、说明、星形装饰及对应编辑字段，保留完整照片环。默认品牌更名 OUR ORBIT，旧默认名称自动迁移；保留照片与其他风格设置。
- 封面右侧三行中文已删除，进入按钮改为小写 `memory`。
- 星河粉、月光蓝、暮色紫、极光绿；自定义名字、星光和速度，立即预览并保存。
- JPEG/PNG/WebP/GIF 批量导入（每批最多 100 张、单张最多 25 MB）；保存原文件和独立缩略图。
- “所有回忆”保留完整照片库，先显示 60 张，再按需加载下一组；搜索与相册筛选仍遍历完整照片库。
- IndexedDB 保存本机照片；创建相册、搜索、收藏、编辑标题/日期/归属、原图下载和删除。
- 大图键盘左右切换、Esc 关闭；响应式移动布局与减少动态效果偏好。
- 十幅本地 SVG 示例插画；导入真实照片后自动隐藏示例。照片不会上传第三方服务。

## 封面外部素材

封面直接使用用户附带提示词内的三条 CloudFront 视频地址，并加载 Google Fonts 的 Figtree 字体。已验证实际视频内容为鲜花/蓝天/飞机，因此按钮改为 PINK SKY、FLOWER WINDOW、GOLDEN BLOOM。视频默认为静音循环播放，有减少动态效果设置时暂停；切换时 1.2 秒交叉淡化，进入相册后暂停所有视频。当前片段优先载入，其余片段按需播放，不同时解码播放全部视频。视频或字体不可访问时，保留静态渐变封面及系统字体，进入相册按钮仍可用。粒子星空和本地照片功能不依赖这些外部素材。

最新参考录屏为 1280×592，带系统提示条，仅作为视觉参考；未将其拉伸或声称为原生 4K 视频。星空实时渲染已在 1920×1080、DPR 2 环境核对实际 WebGL drawing buffer 为 3840×2160。手机按设备像素比绘制。4K 指渲染尺寸，不承诺所有设备达到固定帧率。

保留现有无构建网页结构，通过模块化 CSS/JavaScript 实现提示词的视觉与交互，未为封面迁移 React/Vite/Tailwind。无新增包依赖。

## 明确边界

这是用户确认视觉方向后制作的本机原型，**还不是云端照片仓库**。无真实账号登录、情侣鉴权、双人同步、微信 web-view 接入。原图在当前浏览器和当前 origin 的 IndexedDB 中；清理浏览器数据、切换浏览器或端口会影响访问，请独立保留原图备份。页面明确标识本机存储。

每日精选和 1000 张列表已用模拟数据验证，但大量高清原图可能超过浏览器存储配额。正式导入 1000 多张之前应接入云端文件存储，并保留独立原图备份；当前每批最多导入 100 张，只适合本机试用。

导入日期默认当天，不会读取或推断拍摄日期；可手动修改。GIF 缩略图为静态，详情及下载保留原始文件。HEIC/视频/Live Photo 不在本轮支持范围。

## 云端下一阶段

视觉确认后，再实现微信云开发服务适配：后端验证情侣成员、签发短期会话、私有文件上传下载、分页照片查询和相册管理。现有照片结构需要兼容 `cloudFileID`，并补齐 `coupleId` / `albumId`；不能把本机 IndexedDB 或隐藏入口当成权限隔离。主体与 HTTPS 业务域名资格需确认后再接入小程序 web-view。

## 验证

`npm run check` 检查 JavaScript 语法。交互验证覆盖桌面/手机布局、本地导入后刷新持久化、编辑/收藏/搜索/删除、相册与风格保存；实际结果见任务交付说明。

本轮 Edge 无头验证：三段远程视频解码和切换、封面/相册导航、手机菜单和返回、减少动态效果、星河独立暂停与持久化、远程素材失败时进入相册、无横向溢出，以及原有本地照片操作均通过。验证脚本位于项目 `render_check/album-cover-smoke.cjs` 和 `render_check/album-smoke.cjs`。

最新修改另见 `render_check/album-v3-smoke.cjs`：验证删除指定文本、品牌旧设置迁移、memory 按钮、4K WebGL 缓冲尺寸、动态/暂停像素变化、手机 DPR 3、减少动态效果及关闭 WebGL 后的 Canvas 降级。

长期保存需要云存储原图 + 数据库目录 + 双人访问控制，并另外保存独立原图备份；不能仅连接数据库就称为永久保存。数据库回档也不能替代原图文件备份。
